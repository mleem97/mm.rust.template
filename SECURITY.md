# Security

Do not report secrets, private credentials, or sensitive infrastructure information in public issues.

For security-sensitive reports, use the repository's configured private reporting mechanism.

See the canonical security documentation:

- `docs/security/THREAT-MODEL.md`
- `docs/security/SECURITY-ARCHITECTURE.md`
- `docs/security/SECURITY-CHECKLIST.md`

Agents and automation must follow the least-privilege rules in `.agents/policy/NORMATIVE-RULES.md`.
