# Global Design System

This is the global UI design source.

Feature-specific visual decisions belong in each feature's `design.md`.

## Foundations

Define typography, spacing, colors, elevation, radii, iconography, motion, responsive breakpoints, and focus behavior.

## Accessibility

Define minimum contrast, keyboard, focus, reduced-motion, and screen-reader requirements.

## State language

Use consistent representations for loading, success, warning, error, disabled, empty, offline, and partial failure.

Material changes require a DDR.
