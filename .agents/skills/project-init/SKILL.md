# Skill: Initialize a Rust Project

## Purpose

Interview the user and initialize a project from this template without duplicating agent or documentation infrastructure.

## Procedure

1. Load normative rules and guidance.
2. Read `docs/README.md`.
3. Determine project type and select a blueprint.
4. Ask the minimum required interview questions.
5. Create the project PRD.
6. Create the initial ADR set.
7. Create DDRs for UI/UX work.
8. Create threat model and security architecture.
9. Create the implementation roadmap.
10. Generate task graph input.
11. Validate the graph.
12. Present the plan for approval.
13. Begin implementation only after approval.

## Required choices

The user selects independently:

- project blueprint
- documentation language: English | German
- documentation audience: User | Modder
